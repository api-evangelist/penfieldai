# Penfield.AI

> Penfield.AI is a human-machine intelligence and process-verification platform for security operations. It enforces standard operating procedures across SOC, IAM, MSSP, and GRC teams, delivers real-time analyst productivity insight, and governs AI agents so they follow approved procedures. The platform is self-hosted (Kubernetes / Azure / on-prem) and integrates with tools such as Microsoft Sentinel.

## Docs
- [Documentation](https://docs.penfield.ai/docs/): Deployment, configuration, app integrations (incl. Microsoft Sentinel), and interfaces (Pathfinder for Chrome).
- [Trust Center](https://docs.penfield.ai/trustcenter/): Security and compliance posture (SOC 2 Type II, ISO 27001).

## Notes
- No public REST/GraphQL API, OpenAPI/Swagger spec, or SDK is published; the platform is deployed into the customer's own infrastructure.
- The "Sentinel API" documented under App Integrations refers to consuming Microsoft Sentinel, not a Penfield.AI-provided API.
